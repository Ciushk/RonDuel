# RonTown assets (high-res 4× re-export)

Magenta-keyed, high-quality Lanczos-downscaled sprites for the RonTown isometric town/farm tab in RonDuel.
These replace the earlier 32px-tile set. Sources are detailed illustrations, not true pixel art, so they were
downscaled with an **area/Lanczos** filter (premultiplied alpha, then defringed) rather than nearest-neighbor.

- **Repo path:** `elements-rontown/<name>.png`
- **Raw GitHub URL:** `https://raw.githubusercontent.com/Ciushk/RonDuel/main/elements-rontown/<name>.png`
- **App copy:** copy these files into `apps/web/public/rontown/`, keeping the exact file names.
  The live site serves that public copy, so pushing here does not by itself change production.

## Grid

- Tile sprite: **128×76** (2:1 diamond **128×64** + ~12px earth sides).
- Iso math: `screenX = (col − row) × 64`, `screenY = (col + row) × 32`.
- Shared scale for same-generation art: **128 / 1380** (measured grass width after key+trim).
- Draw back-to-front by `col + row` (then tiles, then objects, then villagers, then badges).
- Buildings and decor have no baked-in ground. Anchor the bottom-center of the sprite on the **front**
  footprint tile’s diamond bottom point `(tileX + 64, tileY + 64)`. For a 2×2, the front tile is the cell
  with the largest `col + row`.
- **Display scale** is independent of the source size. On a 390px-wide phone, draw tiles at about **64–96px**
  wide (and larger on desktop), with ordinary smooth scaling. **Do not** use `image-rendering: pixelated`.
- File names keep Andrei’s originals, including typos (`wather`, `cabage`, `vizit`).
- Villagers: adults **64px** tall, child **52px** (4× the previous 16 / 13). UI buttons **128×128**, badges **56×56**, cursors **~206×128**.
