# RonTown pixel-art assets

Clean, magenta-keyed, native-scale sprites for the RonTown isometric town/farm tab in RonDuel.

- **Repo path:** `elements-rontown/<name>.png`
- **Raw GitHub URL:** `https://raw.githubusercontent.com/Ciushk/RonDuel/main/elements-rontown/<name>.png`
- **App copy:** copy these files into `apps/web/public/rontown/`, keeping the exact file names.

## Grid

- Tile sprite: **32×19** (2:1 diamond 32×16 + ~3px earth strip).
- Iso math: `screenX = (col − row) × 16`, `screenY = (col + row) × 8`.
- Draw back-to-front by `col + row` (then tiles, then objects, then villagers, then badges).
- Buildings and decor have no baked-in ground. Anchor the bottom-center of the sprite on the **front** footprint tile’s diamond bottom point `(tileX + 16, tileY + 16)`. For a 2×2, the front tile is the cell with the largest `col + row`.
- Integer scale only (2× or 3×). `image-rendering: pixelated`.
- File names keep Andrei’s originals, including typos (`wather`, `cabage`, `vizit`).
